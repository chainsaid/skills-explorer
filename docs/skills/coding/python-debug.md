# Python Debug

## 适用场景

- Traceback 分析
- 复杂逻辑断点调试
- 线上问题复现

## 快速流程

1. 最小复现
2. 增加结构化日志
3. 使用 `pdb` 或 IDE 断点
4. 编写回归测试
